
# Как создать персонажа

У класса `ListCharacters`, есть словарь `self.characters`. В нём хранятся все данные о персонажах.
Подробнее: [[class Character & class ListCharacters#class ListCharacters|Класс ListCharacters]]

# Папки

Папка со **спрайтами персонажа** должна находится по пути: 
"./images/characters/\[[[class Character & class ListCharacters#^bb2890|идентификатор персонажа]]\]"

Папка со **звуками персонажа** должна находится по пути:
"./sounds/character_voice/\[[[class Character & class ListCharacters#^bb2890|идентификатор персонажа]]\]"

# Диалоги

Для того, чтобы вести диалог от лица персонажа перед его речью нужно поставить <> , а в них [[class Character & class ListCharacters#^bb2890|идентификатор персонажа]].

### форматирование текста

| ключ | Описание                                            |
| ---- | --------------------------------------------------- |
| \n   | Создаёт перенос строки                              |
| {w=} | Останавливает речь персонажа на определённое время. |
| {f}  | Моментально отображает весь диалог после ключа      |

### Использование переменных
Чтобы вставить значение какой-либо переменной, для этого нужно вставить её название в \[\].
Если нужно использовать квадратные скобки, когда не нужно вставить значение какой-нибудь переменной, то в таком случае перед скобкой ставят символ "\\"

Пример:
```jpy

$ name = "Владислав"

<ps> [name], привет! Давно не виделись!
<ps> \[Квадратные скобки\]

```

# JopaEngine 3000 ToolBox
**JopaEngine 3000 ToolBox** представляет из себя готовый набор инструментов - **Движок**, позволяющий на готовом фундаменте строить свою визуальную новеллу.

В отличии от своего вдохновителя - [Ren'Py](https://www.renpy.org/), **JopaEngine** предоставляет более низкоуровневое программирование, что нацелено на людей, которые разбираются в программировании на **python**.

Во время разработки своих проектов автор имеет прямой доступ к исходным файлам движка и может модифицировать их, как сам тому пожелает.

Движок доступен для компиляции на Windows, MacOS, Linux и Android системах. Осуществляется это при помощи компилятора [Nuitka](https://nuitka.net/), что компилирует python в C++. Были проведены тесты с компиляцией движка, и никаких проблем не возникло.
Да, вы всё ещё можете использовать pyinstaller, но мы настоятельно рекомендуем воспользоваться Nuitka

В качестве библиотеки для графики используется [Arcade](https://api.arcade.academy/en/stable/). Он довольно-таки удобен и прост в  изучении. Он создавался как современная и более простая в использовании альтернатива Pygame.
**Если вы планируете как-либо модифицировать движок, мы настоятельно рекомендуем предварительно ознакомиться с основами Arcade. Это сэкономит вам много времени.**

Мануал (В разработке) движка можно найти поссылке: https://bromander.github.io/JE_wiki/
